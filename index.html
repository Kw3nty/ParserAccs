ParserAccs

Букмарклет для массового парсинга кабинетов Facebook Ads Manager — баланс, траты по любому периоду, лимиты, биллинг, статусы объявлений и привязка к BM в одной таблице с экспортом в CSV.

Как установить

Никаких расширений и установок — одна закладка

1

Покажи панель закладок

Нажми Ctrl+Shift+B, чтобы сверху появилась полоса закладок.

2

Перетащи кнопку

Зажми кнопку ParserAccs выше и брось её на панель закладок. На телефоне — нажми «Скопировать код» и создай закладку вручную.

3

Запусти в Ads Manager

Открой Facebook Ads Manager и кликни по закладке. Готово — таблица кабинетов перед тобой.

Что умеет

📊

Полная сводка

ID, имя, статус, баланс, валюта, траты за всё время и за период, лимит, биллинг, активные и отклонённые объявления, BM.

📅

Любой период

Today, Yesterday, 7/14/30 дней, месяц, Lifetime и свои даты. Популярные периоды — мгновенно из кэша.

🔍

Фильтры и поиск

Все / Активные / Неактивные, поиск по ID, имени и BM, сортировка по любой колонке.

☑️

Выделение

Отмечай кабинеты чекбоксами и копируй ID или выгружай CSV только по выбранным.

📄

CSV для Excel

Кириллица и разделитель sep=, — файл сразу разъезжается по столбцам.

🔒

Read-only

Только чтение через официальный Graph API. Скрипт ничего не меняет в кабинетах.
